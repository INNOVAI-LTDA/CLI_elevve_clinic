# Prompt — Inspecionar features e contratos existentes

Inspecione o repositório antes de implementar.

Objetivo:

Descobrir como o `migration-kit` já organiza:

- backend routes/services/schemas/storage;
- frontend domain/services/adapters/hooks/features;
- contratos de radar, matrix e command-center;
- migrations existentes;
- runtime-stores ou seed data.

Tarefas:

1. Listar arquivos relevantes existentes.
2. Identificar se já existem:
   - feature radar;
   - feature matrix;
   - feature command-center;
   - DTOs de radar;
   - backend service de radar;
   - endpoints existentes.
3. Indicar o melhor ponto de extensão.
4. Não alterar arquivos.
5. Retornar plano de integração.

Critério:

Nenhuma alteração feita. Apenas análise e plano.
