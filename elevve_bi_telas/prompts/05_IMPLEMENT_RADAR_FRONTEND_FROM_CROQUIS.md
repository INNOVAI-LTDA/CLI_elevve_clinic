# Prompt — Implementar frontend Radar baseado nos croquis

Use `docs/UI_SCREEN_MAPPING_FROM_CROQUIS.md` e os assets em `assets/croquis/`.

Objetivo:

Implementar/adaptar tela Radar no frontend React existente.

Componentes desejados:

- Sidebar/navegação conforme croqui.
- Patient summary.
- Radar chart.
- Lista/barras dos pilares.
- Eixo prioritário.
- Tabela técnica opcional para validação.
- Mensagens para configurações pendentes.

Regras:

- Reaproveitar domain/services/adapters/hooks existentes.
- Não criar arquitetura paralela.
- Não buscar pixel-perfect.
- Não embutir croqui como tela final.
- Usar croqui como referência de layout e hierarquia.
